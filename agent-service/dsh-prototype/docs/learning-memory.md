# 第三步：显式学习记忆、纠正和按需摘要

本阶段支持最新学习目标、最新已尝试说明、当前未解决问题、明确表达偏好。仅识别学生原问题中独占一行的四种前缀：学习目标：、已尝试：、未解决：、偏好：。不猜测自然语言意图，不从助手回执或自由摘要提取事实；不是自动构建完整学生画像。

## 用法和存储

原ChatStore/SQLite实例显式调用migrate_learning_memory()，以一个事务从v1升级到v2，保留原聊天；安装不自动升级任何旧文件。未升级则拒绝学习记忆调用，不静默新建或覆盖。新建库仍从v1开始，第二步无记忆调用可继续使用。schema v2增加learning_memory和learning_memory_state两表。

answer_chat(..., learning_memory=store, memory_limits={"max_item_chars":300,"max_prompt_chars":1200})启用。当前要求学习记忆与聊天由同一存储实例协调，以便在最终保存事务中核对记忆epoch；以后平台适配器应提供等价事务保证，不能把两个独立服务的检查说成原子事务。无新增依赖或数据库MCP。

声明示例：

```
学习目标：搭建课程演示页面
已尝试：刷新浏览器；重新打开页面
未解决：页面仍然空白
偏好：请用中文分步骤解释
```

来源为已接受的学生问题request_id及字符start/end，读时再核对原文片段。每种类型一份最新快照，同一问题重复类型/空值/超300字符拒绝，不截断、不部分写入。新问题中的显式声明是更正，递增revision；历史完整原文仍在聊天中。尝试项是最新说明，不是无限追加的全部尝试历史，学生可明确列举多种方法。

目标、尝试、未解决问题严格限存储修订（课程/版本/课时/实例/代次/系统变化即新范围）；偏好仅在同一学生的同一学习记录中跨实例保留，不跨学习记录或其他学生。响应语言等可信应用规则优先，偏好不能授权工具、覆盖课程要求或判断过关。学生说启动了仍是自述，不是观察证据。

## 查看、更正、删除

learning_items(handle)最多返回4项，包含kind/revision/scope_revision、来源及原文；forget_learning(handle,kind,expected_revision=...)显式撤销，旧界面版本不匹配则拒绝。关闭问题可显式撤销open_issue，不从模型语句自动判定解决。

删除记忆不删除原聊天，但会推进history_floor，变更前的旧对话不再给启用学习记忆的模型使用，避免助手旧回声重新引入内容。显式更正同样推进下界；这会保守省略一些无关前文，界面可继续查看，模型会标记上下文不完整。旧声明整轮也不再作为普通历史重放，使用当前规范记忆。

delete_history会同步清空引用该范围原问题的记忆，推进epoch和历史下界；偏好即使已用于新实例，删除其来源也失效。不是物理擦盘或备份删除；需要整体删除原聊天时仍使用相应接口。无自动保留期限或后台清理。

模型运行前记录memory_snapshot/epoch；返回时核对，最终finish在同一写事务再比较expected_memory_epoch。中途纠正或删除时不交付旧答案；未确认保存不声称成功。epoch与VM代次、存储范围revision不同，分别约束记忆变更、实例变更和学习范围。

## 摘要和资源

learning_brief(handle)按需把有效记录原文加标签组合，返回text和带来源items。它是可追溯摘录摘要，不是生成式对话压缩，不调用模型、不持久化重复摘要、不判定知识掌握。更正/删除后重新读取即可得到新摘要。自由语义总结、偏好推断和向量检索未启用。

模型只收到kind/text/source=student_statement，不发送学生身份；最多4项，默认记忆JSON1200字符，硬上限1600，单项最多300。超限整项省略并记录memory_items/memory_omitted；与近期前文、教材共享既有JSON8000字符和完整提示10000字符上限。总输入不能容纳时明确失败，不静默丢掉当前问题。数据库主页容量、锁等待、分页上限延续第一步；无后台模型任务。

## 验收

第三步新增21项测试，合计142项自动回归，覆盖来源伪造、学生隔离、迁移兼容、更正、删除旧回声、跨实例偏好、原文摘要、预算及原子修订检查。sandbox/learning_memory_acceptance.py以受限账号串行测试超出近期窗口的目标、更正和删除，3次新模型请求；数据准备是确定性虚构夹具，不冒充模型生成。实际验收待核对报告，不能把自动模拟测试当模型已理解。

报告sandbox/results/runner-check/learning-memory-report.json，复核development/learning-memory-step3-20261030.json。真实学生、平台界面/HTTP、生产并发、完整课程学习成效和任意模型质量不在本轮范围；第二步已有标识/格式问题继续保留。

## 2026-10-30 实际验收

第三步显式学习记忆核心范围已验收：142项自动检查及3例实际模型核心行为通过，来源和源码/测试指纹一致。目标超出近期窗口仍可使用，更正后采用新目标，撤销后不回用旧目标；摘录摘要同步且无额外模型调用。仍有措辞和同课时多任务关联边界。

三例分别15.29/7.53/6.33秒，均无工具调用，摘录摘要无额外模型调用。来源片段和程序摘要逐项核对。

更正目标后，旧尝试/未解决项仍是同修订下的独立学生快照，系统尚不识别同课时任务切换，不能无条件解释为与新目标相关。correct回答的页面状态是旧自述；forget自由回答遗漏了其余记忆中的未解决项，不能称完整摘要。程序摘要始终由有效记录组成且正确撤销目标。这些质量和任务边界保留在复核报告，不外推为任意语义已验证。
